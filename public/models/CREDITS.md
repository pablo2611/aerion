# AERION Vehicle Asset

The primary vehicle is the **Car Concept** sample asset from the Khronos Group
glTF Sample Assets repository.

- Model and textures: Eric Chadwick / Darmstadt Graphics Group GmbH, 2024
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept
- License: https://creativecommons.org/licenses/by/4.0/legalcode
- Original source design: Unity Fan, public domain (CC0)

The web experience loads the official `glTF-KTX-BasisU-Draco` delivery. Khronos
documents this version as 10.3 MB download size and 14.9 MB video-memory size.
The source asset was already cleaned, UV-corrected, AO-baked, validated, and
compressed for real-time delivery by its authors.

Modifications in this project are limited to runtime material parameters,
lighting, camera presentation, configurator states, and AERION UI. Khronos and
3D Commerce logo / trademark meshes are hidden and are not used as AERION marks.
